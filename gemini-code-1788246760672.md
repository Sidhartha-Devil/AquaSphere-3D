# TASK: UI/UX & Visualization Refactor for INCOIS 3D Ocean Explorer

Refactor the current basic UI prototype into an enterprise-grade oceanographic dashboard matching the layout, telemetry panels, vector particle engine, and data controls in the target interface design.

---

## 1. LAYOUT & NAVIGATION STRUCTURE

Implement a dark-themed (#0A0E17 background) 4-quadrant layout around a central 3D viewport:

### A. Top Navigation Bar
- **Header:** Include "INCOIS 3D Ocean Explorer | Integrated Ocean Data Visualization System".
- **Search Bar:** Centered input with icon ("Search Location...").
- **Navigation Tabs:** Top-right items: `Dashboard`, `Map` (active tab), `Analytics`, `Alerts`, `Settings`, `Help`, and User Profile avatar.

### B. Left Control Panel (Data Layers & Controls)
- **Model Data:** Checkboxes with color-coded legend bars for `Temperature` (rainbow gradient), `Salinity` (blue-green gradient), `Currents` (cyan-yellow gradient), `Chlorophyll`, and `Sea Surface Height`.
- **Observations:** Checkboxes with distinct geometric shapes:
  - `Argo Floats` (Purple Circle ●)
  - `Gliders` (Orange Triangle ▲)
  - `CTD Stations` (Teal Square ■)
  - `BGC Sensors` (Yellow/Green Diamond ◆)
- **Other Layers:** Checkboxes for `Coastline`, `EEZ Boundaries`, and `Bathymetry`.
- **Time Controller:** Horizontal timeline scrubber supporting time offsets (`-48h`, `-24h`, `Now`, `+24h`, `+48h`), date display (`24 May 2025 12:00 UTC`), play/pause toggle, and time-step controls.
- **Depth Slider:** Vertical axis slider with discrete stops (`Surface 0m`, `100m`, `500m`, `1000m`, `2000m`, `Bottom`) and active depth indicator tag (e.g., `500 m`).

### C. Right Panel (Telemetry & Analytics)
- **Selected Platform Card:** Display real-time station details:
  - Status badge (`ACTIVE`), Platform ID (e.g., `2903766`), Type (`Argo Float`).
  - Readouts: GPS Location, Last Report time, Current Depth (`500 m`), Temperature (`18.62 °C`), Salinity (`35.21 PSU`), and Battery percentage.
  - Action Button: "VIEW FULL PROFILE".
- **Model vs. Observation Widget:**
  - Dropdown to switch metrics (`Temperature (°C)`, `Salinity (PSU)`).
  - Comparative metrics table showing `Model Value`, `Observation Value`, and `Difference` (e.g., `+0.17 °C`).
  - Dual-line graph (Depth vs Metric) plotting the Model curve (Blue line) against actual Sensor Observations (Purple line) from 0m down to 2000m depth.

### D. Bottom Dashboard Widgets
- **Vertical Section Cross-Section Plot (Left):** 2D contour profile heatmap along latitude (e.g., `15.25°N`) across longitudes (`70°E` to `90°E`) showing depth-layer values down to 5000m.
- **Recent Floats Table (Center):** Compact list of active platform IDs, UTC timestamps, and operational depths.
- **Quick Access Toolbar:** Action shortcuts (`3D Globe`, `Time Series`, `Profile Plot`, `Data Download`, `User Guide`, `Feedback`).
- **Map Legend Box (Right):** Map key mapping point markers and stream line types (`Surface Current`, `Mid Depth Current`, `Deep Current`, `EEZ Boundary`).

## 2. 3D VIEWPORT & VECTOR STREAMLINE ENGINE

### A. GIS Tools & Header Overlay
- Floating GIS tool widget on top-left of viewport: `Select`, `Pan`, `Rotate`, `Zoom`, `Measure`, and `Reset View`.
- Floating Lat/Lon coordinate pill at top-center of viewport (e.g., `15.250° N, 80.250° E`).

### B. Vector Particle Streamlines (Replacing White Dots)
- Replace static white dot particles with a **WebGL GPU Particle Vector Field Engine**:
  - Sample directional vectors `u_current` (eastward velocity) and `v_current` (northward velocity) from the loaded dataset.
  - Render continuous, curved velocity streamlines with directional flow arrows.
  - **Color-code Streamlines by Velocity/Depth:** Blend colors along streamlines (e.g., Dark Blue = low speed/deep current; Cyan/Yellow/Green = high speed surface flow).
  - Adjust particle opacity, lifetime, and density based on zoom scale.

### C. Interactive Sensor Markers
- Render 3D spatial markers on the globe at exact coordinates corresponding to loaded station records.
- Use distinct 3D glyphs/billboards matching the legend (`●`, `▲`, `■`, `◆`).
- Implement click-to-select logic: Clicking a marker opens its telemetry profile in the right sidebar and updates the Model vs. Observation depth chart.

## 3. DATA BINDING & ACCURACY

Ensure all UI components update dynamically from the uploaded CSV/NetCDF dataset (`latitude`, `longitude`, `depth`, `temperature`, `salinity`, `u_current`, `v_current`):
1. **Depth Slicing:** Dragging the vertical depth slider filters the 3D volumetric rendering layer and 2D vector streamline plane to show data at that specific depth layer.
2. **Timeline Playback:** Scrubbing the time control updates particle velocities and float sensor readings to match the exact `timestamp` row.
3. **Color Bar Synchronization:** Display a dynamic color ramp legend at the bottom of the viewport showing min/max range (e.g., `0°C` to `35°C`) bound to the selected active variable layer.
